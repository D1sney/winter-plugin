# Winter Magic ❄️

Новогодний плагин для браузера — падающие снежинки и гирлянда на любом сайте.

![Winter Magic Preview](https://via.placeholder.com/800x400/1c1c1e/ffffff?text=Winter+Magic)

## Установка

### 1. Скачай плагин

**Вариант A (если знаешь git):**
```bash
git clone https://github.com/ваш-username/winter-plugin.git
```

**Вариант B (для всех):**
1. Нажми зелёную кнопку **Code** → **Download ZIP**
2. Распакуй архив в любую папку

---

### 2. Установи в браузер

#### Chrome / Yandex Browser

1. Открой браузер и перейди на страницу расширений:
   - **Chrome:** `chrome://extensions/`
   - **Yandex:** `browser://extensions/`

2. Включи **Режим разработчика** (переключатель в правом верхнем углу)

3. Нажми кнопку **Загрузить распакованное расширение**

4. Выбери папку `winter-plugin`

5. Готово! Обнови любую страницу — снежинки уже падают ❄️

---

## Как использовать

- **Открыть настройки:** `Ctrl + S` (Mac) или `Alt + S` (Windows)
- **Закрыть:** клик вне окна или `Esc`

### Что можно настроить

**Снежинки:**
- Включить/выключить
- Количество (20-100)
- Размер (S, M, L)
- Скорость падения

**Гирлянда:**
- Включить/выключить
- Яркость
- Мигание

Все настройки сохраняются автоматически и работают на всех вкладках.

---

## Удаление

1. Перейди на `chrome://extensions/` или `browser://extensions/`
2. Нажми **Удалить** на карточке Winter Magic
